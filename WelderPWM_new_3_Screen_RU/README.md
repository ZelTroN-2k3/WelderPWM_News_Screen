# 🔥 Автоматический Сварщик 3D-Филамента (ШИМ и NTC-Терморегуляция)

[![Arduino](https://img.shields.io/badge/Platform-Arduino%20Nano%20V3-blue.svg)](https://www.arduino.cc/)
[![Firmware](https://img.shields.io/badge/Version-v3.8%20Alpha-brightgreen.svg)]()
[![Language](https://img.shields.io/badge/Language-C%2B%2B%20%2F%20Arduino-orange.svg)]()
[![License](https://img.shields.io/badge/License-Open%20Source-green.svg)]()

> **Высокопроизводительная модульная C++ прошивка для устройства сварки и переработки 3D-филамента.**  
> Интеллектуальное терморегулирование по замкнутому контуру с датчиком **NTC 100k**, графический **OLED 128x64 HUD** дисплей с анимацией в реальном времени, сохранение настроек в **EEPROM**, активная защита от перегрева и удобное управление **одной кнопкой**.

## 🌟 Основные Возможности

### 🌡️ 1. Умная Терморегуляция (Замкнутый Контур)
* **Высокоточное измерение температуры NTC 100k B3950** на аналоговом пине `A0` с 8-кратной передискретизацией и уравнением Стейнхарта-Харта.
* **Быстрый преднагрев (Начальный Boost)**: Повышенная мощность ШИМ на этапе набора температуры для преодоления тепловой инерции нагревательного блока.
* **Активное удержание температуры**: Точная стабилизация температуры во время диффузионной сварки/соединения прутка.
* **Интеллектуальное охлаждение**: Вентилятор работает на этапе остывания и автоматически отключается, как только блок остынет ниже **45°C**.

### 🎨 2. Графический Интерфейс OLED 128x64 (HUD и Анимации)
* **Анимированные мини-иконки текущей фазы**:
  * ⚡ **Форсированный нагрев (Boost)**: Динамическая анимация молнии.
  * 🔥 **Догрев до цели**: Пульсирующий термометр.
  * ↔️ **Удержание / Сдвиг**: Осциллирующий курсор и стрелки движения прутка влево/вправо.
  * 🌀 **Охлаждение**: Вращающийся 4-лопастной вентилятор.
* **Современный структурированный HUD**: Крупное название материала, целевая температура (`280°C`, `230°C`, `190°C`), обратный отсчет таймера и калиброванные сообщения ($\le 21$ символа).
* **Динамическая полоса прогресса**: Отображение в реальном времени прогресса фазы ($25^\circ\text{C} \rightarrow T_{\text{цель}}$).
* **Двухступенчатый хранитель экрана**: Анимация «Дождь искр» через 1 минуту бездействия и полное отключение OLED через 2 минуты для защиты от выгорания пикселей.

### 🕹️ 3. Эргономичное Управление Одной Кнопкой
* **Главное Меню**:
  1. `1. Режим PET` (Цель $280^\circ\text{C}$)
  2. `2. Режим PETG` (Цель $230^\circ\text{C}$)
  3. `3. Режим PLA` (Цель $190^\circ\text{C}$)
  4. `4. Режим Custom` (Настраиваемая температура от $150^\circ\text{C}$ до $290^\circ\text{C}$)
  5. `5. [ НАСТРОЙКИ ]` (Подменю полной конфигурации)
* **Принудительное Охлаждение (30 сек)**: Активируется быстрым **тройным кликом** из главного меню для быстрого остывания перед выключением.

### ⚙️ 4. Меню Настроек и Память EEPROM
* Настройка таймаутов безопасности, времени удержания, охлаждения и работы вентилятора.
* `Целевая темп Custom`: Изменение целевой температуры пользовательского режима с шагом $5^\circ\text{C}$.
* `Всего спаек`: Энергонезависимый счетчик общего количества успешных сварок.
* `Инверсия экрана`: Переключение между классической темой (Черный фон) и инвертированной (Белый фон / Черный текст).
* `! Сброс настроек`: Быстрый сброс параметров к заводским установкам двойным кликом.

### 🛡️ 5. Активная Тепловая Безопасность
* **Защита от обрыва / КЗ датчика**: Мгновенное отключение нагревателя с выводом ошибки `ОШИБКА ДАТЧИКА NTC`.
* **Защита от неконтролируемого перегрева (*Thermal Runaway*)**: Аварийное отключение нагрева при $T > 295^\circ\text{C}$ и вывод предупреждения `ПЕРЕГРЕВ НАГРЕВАТЕЛЯ !`.
* **Аварийная остановка пользователем**: Одиночный клик во время сварки мгновенно прерывает нагрев и включает охлаждение.

### ⚡ 6. Оптимизированное Использование Памяти
* Тексты меню и экранов размещены во Flash-памяти (`PROGMEM` / `PSTR`), освобождая **более 950 байт свободной оперативной памяти SRAM** (занято всего ~53% ОЗУ на ATmega328P).

## 📐 Схема Подключения (Arduino Nano V3)

| Компонент                 | Вывод компонента                     | Пин Arduino Nano V3                | Примечания                                                      |
| :------------------------ | :----------------------------------- | :--------------------------------- | :-------------------------------------------------------------- |
| **Кнопка**                | Вывод 1 / Вывод 2                    | **D10** / **GND**                  | Использует внутреннюю подтяжку `INPUT_PULLUP`                   |
| **Нагреватель (MOSFET)**  | Затвор (Gate через 100 Ом)           | **D3** (PWM)                       | ШИМ-управление силовым нагревателем                             |
| **Вентилятор 5V/12V**     | Управление (Транзистор/MOSFET)       | **D2**                             | Принудительное охлаждение и продувка                            |
| **Красный LED**           | Анод (+ через резистор) / Катод      | **D8** / **GND**                   | Индикация нагрева и аварий                                      |
| **Зеленый LED**           | Анод (+ через резистор) / Катод      | **D6** / **GND**                   | Индикация готовности и охлаждения                               |
| **Датчик NTC 100k**       | Вывод 1 / Вывод 2                    | **A0** / **GND**                   | Делитель напряжения с резистором $47\,\text{кОм}$ к **+5V**     |
| **OLED Дисплей I2C**      | SDA / SCL / VCC / GND                | **A4** / **A5** / **5V** / **GND** | SSD1306, SSD1309 или SH1106 (128x64)                            |
| **Зуммер (Опция)**        | (+) / (-)                            | **D4** / **GND**                   | Включается через `#define ENABLE_BUZZER 1`                      |

### Схема подключения терморезистора NTC 100k (Пин A0)

```
                         +5V (Arduino)
                            │
                        [ 47 кОм ] (Подтягивающий резистор 0.25Вт)
                            │
     Пин A0 Arduino ────────┼──────────────────────┐
     (Аналоговый вход)      │                      │
                       [ NTC 100k ]           [ 100 нФ ] (Опциональный фильтр)
                            │                      │
                           GND ────────────────────┘
```

## 🛠️ Установка и Прошивка

### 1. Необходимые Библиотеки (Arduino IDE)
Установите следующие библиотеки через Менеджер библиотек Arduino IDE:
* **`U8glib`** (автор *oliver*): Быстрый I2C драйвер OLED дисплеев.
* **`EncButton`** (автор *AlexGyver*): Обработка нажатий кнопки (клик, двойной клик, тройной клик).
* **`Wire`** и **`EEPROM`**: Встроены в базовое ядро Arduino AVR.

### 2. Настройка Arduino IDE
* **Плата**: `Arduino Nano`
* **Процессор**: `ATmega328P` (или `ATmega328P (Old Bootloader)` в зависимости от чипа Nano)
* **Порт**: Выберите соответствующий COM-порт.

### 3. Компиляция через консоль (Опционально с `arduino-cli`)
```bash
arduino-cli compile --fqbn arduino:avr:nano:cpu=atmega328old .
arduino-cli upload -p COM3 --fqbn arduino:avr:nano:cpu=atmega328old .
```
